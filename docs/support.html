Opening files

How do I open a file?

Any of these:

  • Double-click a Markdown file in Finder (once Plainview is your default app for it, see below).
  • Drag the file onto Plainview's window or its Dock icon.
  • File › Open… (⌘O).
  • File › Recently Read for the last 10 files.

Each file opens in its own window.

How do I make Plainview open Markdown files when I double-click them?
  1. In Finder, select any .md file and choose File › Get Info (⌘I).
  2. Under Open with, choose Plainview.
  3. Click Change All…, then Continue.

Repeat for .markdown or .txt files if you want those to open in Plainview too.

Which files can Plainview open?

Markdown files ending in .md, .markdown, .mdown or .mkd, and plain text files ending in .txt. Files in UTF-8 work best; older files in other encodings, such as Windows-1252 or UTF-16, are usually detected automatically.

Can I edit a document in Plainview?

No, and that's on purpose: Plainview is a reader, so you can't change a document by accident. To edit, open the file in any text editor and keep Plainview next to it. Plainview reloads the document every time you save.

Which Markdown features are supported?

Standard Markdown (headings, emphasis, lists, quotes, code, links, images, horizontal rules) plus the GitHub-style extras: tables, checklists and strikethrough. HTML inside a document is shown, but documents can never run scripts.

Quick Look

How do I preview a file in Finder?

Select a Markdown file in Finder and press Space. Plainview's Quick Look extension shows it rendered, with the same layout as the app.

Space shows plain text instead of the rendered document
  1. Make sure Plainview is in your Applications folder, and open it once. macOS only finds the Quick Look extension after the app has been opened.
  2. Check the extension is turned on. On macOS 15 or later: System Settings › General › Login Items & Extensions, then click the info button next to Quick Look and turn on Plainview. On macOS 14: System Settings › Privacy & Security › Extensions › Quick Look.
  3. If another app also previews Markdown, macOS uses only one of them. Turn the other one off in the same place.
Images don't show in Quick Look

Quick Look only lets an extension read the file being previewed, so images stored in other folders appear as a labeled placeholder. Open the document in Plainview to see them.

Reading

How do I change the typeface, size or width?

Everything is in the View menu:

  • Font: System Sans, System Serif, Georgia, Palatino or Charter.
  • Zoom In, Zoom Out and Actual Size (⌘+, ⌘−, ⌘0).
  • Wider and Narrower (⌘], ⌘[) set the line width.
  • Justify Text (⌘J).

Your choices apply to every window and are remembered next time.

How does dark mode work?

Plainview follows your Mac's light or dark appearance. View › Dark Mode (⌘D) keeps it dark even when your Mac is in light mode; turn it off again to go back to following the system.

The document doesn't update when I save it

Plainview watches the file and reloads it within a moment of every save, including from editors that save by replacing the file. If the file was moved or renamed, open it again from its new location.

How do I search a document?

Edit › Find… (⌘F) opens the find bar. ⌘G and ⇧⌘G move between matches, and Esc closes it.

Images & links

"Some images are in …, which Plainview needs permission to read."

macOS only lets Plainview read the files you open, not the folders around them. If your document shows images stored next to it, click Allow Access… in the bar at the top of the window and choose the folder (Plainview suggests the right one). The images appear right away, and Plainview remembers the folder for next time.

Images from the web don't load

Images linked with https:// addresses load directly from the web, so they need an internet connection. Check that the address works in your browser.

What happens when I click a link?
  • Links to headings in the same document, like [Setup](#setup), scroll to that heading. They use the same anchor names as GitHub.
  • Links to other Markdown files open them in Plainview.
  • Web and email links open in your browser or mail app.
  • Links to PDFs, images and videos open them in their usual app. Any other file is shown in Finder rather than opened, so a link in a document can never run a program.

Printing & PDF

How do I print or save a PDF?

File › Print… (⌘P) prints with your current typeface and text size, on the paper size set in File › Page Setup… (⇧⌘P). Page breaks fall between lines, never through them.

File › Export as PDF… saves a PDF with the same layout, in which links to websites, email addresses and headings stay clickable.
